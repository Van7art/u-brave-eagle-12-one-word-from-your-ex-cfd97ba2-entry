One Word From Your Ex: **Delivered**

One word from your ex: **Delivered** — as in the read receipt: delivered, never replied to. It stings, it lands instantly, and it is the freshest pick in the field (1 copy). The other candidates — 'Unfinished' and 'Read' — are kept in `vA/`, `vB/`, `vC/`; vA was chosen because a delivery status as a character verdict is the sharpest surprise.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 26.13.1 per the kit).
The program writes exactly the entry above to `/output/entry.txt` — no
trailing newline, so the file holds exactly the entry — and prints exactly
that text to stdout. It uses no network, no randomness, no clock and no
environment input, so two runs produce byte-identical output.
